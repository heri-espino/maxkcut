# Experiment037 LaTeX project

Build from this directory: `latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex` and `latexmk -pdf -interaction=nonstopmode -halt-on-error dashboard.tex`. Both use shared STIX2 style. Figures and generated TeX are included; compact data under data/ is sufficient to regenerate figures using scripts/experiment037_report.py (also copied into this project). Install AwesomeFigures at d673decd59132094d0763c9e22d4fd6098ff6def, numpy, matplotlib. Raw candidate partitions and directions are retained only on VM; storage manifest includes original file paths and checksums. The dashboards have exactly 96 pages and main appendix is separate. No rerun of numerical optimization to edit or compile. The references are fixed, not necessarily global optima. See notes/experiments/experiment037-best-known-dashboards.md.
