# Mathematical monographs

Each monograph is a self-contained source project. Preserve its modular LaTeX
sources, figures, code, supporting data and verified compiled PDF together.

## Available monographs

- **[Max-Cut SDP, Gram factorization, and Efficient Vector Ascent](eva-maxcut/README.md)**
  — two-part, 49-page mathematical exposition with 20 LaTeX input modules,
  analytic primal–dual certificates, a five-cycle and a weighted six-vertex
  wheel example, reproducible code, and archived plots.
  [Read the PDF](eva-maxcut/EVA_MaxCut_Theory_and_Examples.pdf) or
  [edit main.tex](eva-maxcut/main.tex).

New work should use a stable descriptive slug, have a buildable entry point,
and document theoretical caveats and validation evidence. Experimental
results should use sequential identifiers and retain original provenance.
