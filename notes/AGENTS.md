# Notes-specific instructions for research agents

Read the repository root `AGENTS.md` first.

- `notes/background/`: bibliographic/source-grounded notes. Cite **original paper and PDF page/section** for claims; identify derived lemmas and conjectures in distinct subsections.
- `notes/experiments/`: one note per independent study, with hypotheses, exact commands, seed policy, graph IDs, solver settings, diagnostics and results or an explicit **not yet executed** status.
- Never edit historical experimental claims to make new code look better. Append a dated correction with a reason instead.
- Do not reuse G-set's Max-Cut outcomes as evidence for Chapter 7's A/B/C/D benchmark.
- Do not include imaginary plots/tables, claimed p-values, or benchmark comparisons with undocumented compute budgets.
- Prefer Markdown and mathematical notation supported by GitHub. Keep links relative within the repository.
